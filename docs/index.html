Quick answers

Good questions. Simple answers.

A few things worth knowing before your first drop.

Is Droply free?

Yes. Droply is free to use, with no account needed to start sending.

Do both people need to be online?

Yes. Files move directly between devices, so both people need to have Droply running and be connected when the transfer takes place.

Is there a file size limit?

No server sets a maximum file size. The practical limits are things like available storage, connection stability, and how long a transfer takes.

How are my files protected?

Transfers use encrypted device-to-device connections. The receiver approves each transfer, and both people verify a matching six-digit code before any file data is sent. Droply doesn't upload the files to cloud storage.

Where is my device code, and what if it changes?

Your device code is available under Settings → Profile. It stays the same as long as your device identity is preserved. If you lose your saved connection credential, recovery may restore access without changing the code. If you create a new identity, you'll get a new device code and need to add your contacts again.
